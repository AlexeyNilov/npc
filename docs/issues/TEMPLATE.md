# ISSUE-NNN: Concise problem title

**Status:** Open | Routed | Resolved | Accepted tradeoff

**Observed:** YYYY-MM-DD

**Scope:** Affected product surface or experiment

## Problem

State one observable, unresolved problem. Do not prescribe a solution here.

## Evidence

- Reproduction command, scenario, trace, test, or short transcript.
- Actual result and the relevant expected product outcome.

## Impact

State the product outcome this problem blocks, weakens, or makes uncertain.

## Open question

State the smallest unanswered question or consequential choice.

## Routing

- **Requirements:** link when observable behavior is accepted.
- **Architecture:** link when the verified current mechanism is recorded.
- **Decision:** link when a consequential choice is accepted.
- **Roadmap:** link when a future outcome is selected.
- **Task:** link only when execution is ready.

## Resolution

For Resolved or Accepted-tradeoff status, link the verification evidence and
canonical resolution. Otherwise write `Pending`.
