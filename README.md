# Python template

Minimal Python 3.12+ project with a `src` layout, setuptools packaging,
pytest, Ruff, and strict mypy checks. No runtime dependencies.

See [installation](doc/install.md) and [contributing](CONTRIBUTING.md).

To start a new project, copy this directory, change the project name and
description in `pyproject.toml`, rename `src/python_template`, and update the
import in `tests/test_package.py`. Replace this README with your project overview.
